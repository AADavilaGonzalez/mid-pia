# High level language feature overview

## Included
- pointers
- arrays
- slices
- compount types
- stack memory allocation
- type casting between primitives
- type composition

## Excluded
- pointer literals
- null valued pointers
- dynamic memory allocation
- pointer arithmetic
- array arithmetic
- non array aggregate types (structs, unions, tuples)
- aggregate initialization
- multiple return types
- constness
- referencess
- variable shadowing
